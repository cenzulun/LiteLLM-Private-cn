# 统一 ARM64 交付验收范围

网关版本 1.0.10 增加完整路由监控页面，合并原令牌总览、路由在线发布、登录页、兼容协议修复与推理调度模块。交付应用镜像仅为 ARM64，最终打包检查 Docker save 清单中的每个镜像架构，Motor 原生文件验证沿用同一未更改镜像的历史证据。

构建、运行与持久化测试的原始输出在 verification 目录。Motor 进程健康不代表模型就绪，未接入真实引擎时不宣称 ready=true。现场仍需验证 openEuler ARM64、十四台服务、Motor 引擎协议兼容性、真实流式推理、吞吐、故障恢复及完整断公网运行。

本包是内网验收候选，不以本地 ARM64 仿真运行替代昇腾实机验收。外部 PostgreSQL、Redis、Prometheus、昇腾导出器、Kubernetes 推理服务和模型权重不在应用镜像包内。

本地统一 Compose 使用两个真实 ARM64 镜像运行，已验证 Motor 两个原生文件均为 ARM64、共享库可实际加载、网关能保存连接并隐藏凭据、Motor 管理接口可达、空实例时模型明确未就绪。离线镜像归档已实际重新导入。

首次 ARM64 仿真迁移触发默认 600 秒超时，留下一个迁移开始记录。对同版本 SQL 与隔离测试数据库逐项核对后，使用官方命令标记已应用；随后余下迁移全部成功。交付配置将迁移等待提高为可配置的 1800 秒，保留失败迁移的启动保护。该恢复操作只针对本地独立测试库，不是对生产数据库的操作。


本版修复地址范围误判、接口路径误翻译以及基础 Compose 缺少调度服务的问题。新增回归验证使用合成地址，未包含生产地址或密钥。

本版地址和调度回归共 21 项通过，接口类型中文展示与协议原值回归 3 项通过。技术路径审计无待修复项。实际管理接口已验证合成 148 地址可保存为模型、监控源及调度连接，测试完成后清理测试数据并恢复原监控配置。统一 ARM64 运行及重启后的连接、加密凭据和密钥持久化验证通过。


兼容协议修复新增验证：前端提交三种历史兼容接口标识均为 openai；服务端规范化请求体；真实 Router 调用本地 HTTP 模拟服务，验证四种标准或历史配置的普通与流式对话、上游实际模型名称与 token 用量。模拟服务验证不替代生产 DeepSeek 模型验收。

历史 ARM64 完整运行与重启持久化日志属于 1.0.8 的回归基线，不代表每份历史日志均由 1.0.9 镜像产生；本次 1.0.9 协议测试见带 1.0.9 版本号的证据文件。
