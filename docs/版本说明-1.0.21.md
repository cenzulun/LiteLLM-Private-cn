# 1.0.21 更新说明

本版按页面批注逐项调整管理与监控操作，升级保留现有模型、调用密钥、路由配置、数据库和数据卷。

| 批注 | 调整 |
| --- | --- |
| 1 | 密钥表移除团队列，扩大密钥名称列，增加查看密钥、编辑模型授权和删除操作。删除需确认，调用鉴权同时失效。 |
| 2 | 创建新密钥按钮靠左展示。 |
| 3 | 已部署模型每行增加修改按钮，编辑对外模型名称、上游模型标识、地址与密钥；密钥留空保留原值，其他参数不覆盖。 |
| 4 | 推理监控操作栏靠左，模型实例选择紧随配置与刷新按钮，同一行展示，窄屏自动换行。 |
| 5 | 推理监控分为趋势指标、采集实例与模型、全部指标明细、原始指标与标签四个页签；切换后直接显示内容。支持选择多个实例，在同一指标图中用不同颜色展示。每个实例使用独立样本，不跨实例填补缺失数据。 |
| 6 | 路由监控操作栏靠左。 |
| 7 | 保留真实模型节点添加、删除与备用连接，增加清空画布重新编排入口。节点必须绑定已接入模型；删除画布节点不会删除模型服务。 |
| 8 | 画布默认高度提高，支持拖动调整高度；连接关系与优先级入口移到连接类型之后，不再占用画布下方空间。 |

## 调用密钥查看

完整密钥只对可写平台管理员开放，不在列表、浏览器持久化存储或查询缓存中保存原文。本版新建密钥在服务端使用固定加密盐值加密，保存在原有持久化卷，打开查看窗口后即时读取，关闭清除前端值。已删除密钥不能查看。

升级前的密钥如果只保存了不可逆摘要，无法恢复原文，页面明确提示。旧密钥继续有效，无需替换；确需再次分发时，可新建密钥并更新调用方后删除旧密钥。不要覆盖原 `LITELLM_SALT_KEY`，否则加密数据无法解密。

## 升级

只需更新网关镜像。把离线包中的 `all-images-arm64.tar`、`SHA256SUMS` 和 `upgrade_gateway.sh` 放到原部署目录，执行 `sh upgrade_gateway.sh`。保留原 `.env`、配置和数据卷，不重新初始化。

告警历史从本版采集开始积累，不虚构升级前未保存的告警。多模型对比须各采集源具有对应指标历史；没有数据的曲线如实留空。
