# 1.0.13 更新说明

## 监控接入

新增源采集：直接访问独立推理实例、设备导出器或网关的 `/metrics`，支持 API Key、采集周期、连接超时、证书验证、模型标签过滤及部署关联。原 Prometheus 配置和查询入口保留，两种数据分别展示。

监控页面顶部提供“配置源采集”“配置监控源”和“刷新”。配置默认收起；未接入的数据区、无数据趋势和无活动告警区域隐藏。统计说明折叠展示，错误状态保留可操作提示。推理、资源、路由和告警页面共用配置入口。

## 指标与历史

- 运行、排队请求数，输入输出令牌累计与吞吐，每秒完成请求数和缓存占用率。
- 首令牌、排队、端到端、预填充、解码等时延的累计平均值、窗口平均值及窗口第九十五／九十九分位。
- 前缀缓存命中率、推测解码接受率、进程内存与文件数。
- 全部采集实例概览、汇总指标筛选、历史趋势、原始指标与标签搜索。

后台持续采集，不依赖浏览器。采集配置与加密密钥保存在现有 PostgreSQL，趋势位于原持久化卷。空闲时吞吐零值有效；没有新观测的时延不使用累计值冒充实时值。计数重置、采集异常与过期样本分别处理。

源采集可按模型部署关联用于运行与排队压力路由，缺少新鲜数据时回退到原历史时延策略。设备资源必须接入实际设备导出器，不能从普通引擎指标推算。

## 本版边界

文本快照用于本地回放测试，未提供页面文件导入或普通日志解析。原始扩展指标可查看最近采样，历史趋势仅保存预置汇总指标。站内活动告警没有通知推送与历史归档。单机历史最多二十五万条采样，十四个实例每十秒采样时约保存两天；多主机集中存储需保留 Prometheus 或另行规划。

升级保留原 `.env`、数据库、加密盐值、Compose 项目名及持久化卷，仅更新镜像，不重新初始化。单网关容器更换存在短暂中断。离线包同时包含网关和调度服务的 ARM64 镜像；本地仿真测试不替代目标 openEuler ARM64 主机和真实生产引擎验收。
