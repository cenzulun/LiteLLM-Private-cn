# 1.0.17 全站页面布局统一

- 顶部栏保留一个页面主标题，正文去除重复的大标题与副标题；共享页面组件在后台上下文中自动省略重复页头，保留创建、刷新及配置操作。
- 统一正文页边距和主要区块间距，修正模型、密钥、团队、用户、监控、策略、缓存、日志与设置模块的嵌套留白。
- 移除常驻快捷键提示、重复模块介绍及无助于操作的说明；错误、告警、权限提示、必要参数说明和统计口径继续保留。
- 推理和资源页直接进入配置操作及实例数据，首页去除重复介绍，路由校验、发布、回退操作移至画布上方。
- 内容区域的二、三级标题使用统一字号；登录页的背景、大标题及配色保持既有设计。

本版没有后端接口或数据库结构变更，保留 1.0.16 的路由、监控、配置和持久化能力。已有部署在原目录沿用原环境、项目名及持久化卷升级，不需要初始化。
