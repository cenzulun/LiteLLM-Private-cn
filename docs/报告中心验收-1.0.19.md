# 报告中心验收 1.0.19

原问题已在普通 HTTP 内网域名浏览器环境复现：安全上下文为否，浏览器未提供随机编号接口，旧版点击生成后提交请求数为零，并显示通用失败提示。修复后在相同环境中成功提交报告和对话修订，任务配置可保存独立生成要求。

前端四项交互测试通过，覆盖 HTTP 兼容、报告详情、对话修订和定时任务配置。原报告后台十一项测试通过，新增定时任务后台七项测试通过，覆盖北京时间下次执行、权限、启停、配置冲突、停机补执行、防重复、队列容量及生成要求传给分析模型。

桌面、平板和手机宽度一千四百四十、七百六十八及三百九十像素下检查了默认展开的生成要求和任务配置。每周执行控件正常，没有页面横向溢出或页面脚本错误。

AMD64 正式镜像使用本地模拟模型验证后台到期调度，未手动调用报告生成接口。双工作进程仅生成一份报告，任务的模型、生成要求、统计范围均被使用。停用任务并重启容器后，任务、停用状态与报告仍保留。

生产构建及类型检查通过，代码规范检查没有错误，存在九项复杂度和表达式风格警告。镜像与部署包的最终架构、文件一致性及 ARM64 功能验证结果以包内验证记录为准。目标 openEuler 主机与真实内网模型仍需现场验收。
