# Motor 模块界面约定

Mode: Operate。沿用现有中文后台的 Page、PageHeader、Button、Input、Select、表格、字体、颜色和间距。管理员日常从服务列表选择模型池，完成配置、连接检查、模型绑定、实例操作和监控。

## Direction contract

THESIS: 用真实连接和动作结果组织推理调度工作，配置、纳管、监控有可追踪的状态。

OWN-WORLD: 继承现有后台中性背景、主色按钮、细边框、紧凑表单和可横向滚动的数据表。

STORY: 首次进入可创建连接；保存后可检查每个端口、接入 LiteLLM、查询实例、执行受控变更并验证结果。

FIRST VIEWPORT: 顶部标题与新增连接动作，左侧服务选择，右侧连接状态及页签；未配置时直接展示连接表单。

FORM: seed: none (pinned)。用户要求“独立模块嵌入到LiteLLM里面”“页面要能支持配置连接”。这是现有后台的功能扩展，保留现有视觉体系。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
