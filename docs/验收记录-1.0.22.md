# 1.0.22 操作列调整验收记录

本次仅修正已部署模型列表的操作位置。旧版浏览器验证记录显示两个操作表头，修改按钮位于第一列。

最终页面验收检查仅有一个操作列，修改位于原有右侧操作列，启停和删除仍在同一单元格。使用临时模型打开修改窗口并保存服务地址，再通过模型接口核对保存结果，完成后删除临时模型。分别检查 1454 与 1024 像素视口，确认右侧操作仍可见。

构建及验证结果随包保留在 `verification` 目录。后台代码与已经通过 ARM64 完整启动的 1.0.21 相同。新 AMD64 镜像完整启动后进行页面验收，新 ARM64 镜像核对架构及页面、后台文件一致性，本版没有重复 ARM64 完整服务启动，也未在目标 openEuler 主机或生产推理引擎验收。

升级保留原环境文件、数据库和数据卷，不重新初始化。1.0.21 的其他页面功能继续保留。
