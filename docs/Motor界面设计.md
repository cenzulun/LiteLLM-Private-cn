# Motor 管理界面

本模块延续现有 LiteLLM 中文后台的 Operate 界面。与项目既有 Page、PageHeader、Input、Button 和 Tabs 共用字体、前景色、中性背景、细边框及间距，不另建品牌体系。

默认页面以当前连接、就绪状态、五项接口检查和真实指标展开。首次使用直接进入配置表单。连接根地址、模型名、部署模式、独立管理和推理密钥可在页面设置。凭据输入为密码框，保存后不回显；空值保留与明确清除分别处理。

通过五个可链接页签组织状态与指标、实例纳管、网关接入与测试、连接配置、操作记录。URL 查询参数 `motorTab` 保存当前页签。指标缺失显示“待采样”，HTTP 连通与 ready=true 分开表达，不使用示例吞吐或节点数据。

桌面表单使用双列，手机改为单列。手机连接选择占独立整行，表格和页签在自己的区域横向滚动。状态列表支持换行；操作错误、等待、空态及只读管理员状态明确显示。

策略字段从当前官方有效配置初始化。切换连接会重建策略表单，避免前一连接草稿被用于另一服务。应用按钮需要勾选重启确认，并提示重放拓扑及重新检查就绪。没有配套控制服务时不展示可点击的策略应用操作。

页面没有新增位图资产。采用现有组件和图标。桌面 1440×1050、手机 390×844 截图存于 `.impeccable/review`，另有手机下半页指标及策略截图。独立评审代理未成功收到任务，因此完成评审在当前线程按同一审核清单执行，结论单独记录。真实模型与内网验收结果不属于视觉通过范围。
