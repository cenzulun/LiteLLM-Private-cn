# 1.0.14 展示范围修正

隐藏规则仅应用于推理监控等页面的 Prometheus 区域，保留其顶部“配置监控源”入口。新增 `/metrics` 源采集面板正常显示：未配置时保留接入提示，空闲时保留零吞吐，窗口时延没有样本时保留指标及说明，趋势筛选和源采集告警区不再因暂无数据消失。

撤回“引擎与昇腾资源”页的操作栏与隐藏调整，恢复其独立标题、刷新按钮、配置区、资源状态、资源表格与趋势区，同时保留新增源采集能力。其他页面继续使用顶部“配置源采集”“配置监控源”“刷新”的布局。

本版只修正前端展示，后台采样、指标计算、数据库和持久化卷保持原行为。升级只更新网关镜像，保留原 `.env`、加密盐值、Compose 项目名和持久化卷，无需重新初始化。单网关容器更换有短暂中断。
