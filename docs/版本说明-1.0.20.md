# 1.0.20 更新说明

本版沿用现有数据库、缓存、模型登记、采集配置、报告及定时任务，仅更新网关镜像。完整离线包同时包含 ARM64 网关与推理调度服务镜像。

## 功能修复

- 用户详情恢复信息展示和编辑入口，可修改用户名称、邮箱、角色、模型权限及请求限制；只读管理员不能修改。用户标识作为数据库关联键保留。
- 报告参数校验显示具体字段或时间问题。生成要求最多一万个字符；允许结束时间相对服务器存在五分钟以内的时钟偏差。超过偏差时应校对客户端和服务器时间。
- 分析模型默认响应等待时间由两分钟延长至五分钟，支持通过 `REPORT_MODEL_TIMEOUT_SECONDS` 配置为三十至六百秒。模型本身的超时、上下文或输出长度限制仍可能影响生成。
- 失败报告区分指标汇总、模型响应超时、鉴权、限流、连接、上下文不足、输出截断、正文为空及格式错误。对完整自然语言分析使用固定模板安全排版，保留数据章节和图表；不执行模型返回的页面代码。
- 指标汇总成功后立即保存数据快照。分析失败后可在详情中重新选择模型、填写要求并点击“生成”；沿用已保存快照。汇总失败而无快照时会重新汇总原时间范围。
- 详情对话区支持拖动分隔线或使用左右方向键调宽；报告列表支持修改内容、重命名和删除。修改内容生成新版本，保留原报告。正在生成的报告需完成后再重命名或删除。
- 七天趋势固定展示所选时间范围，跨日显示日期，并标记实际有效采样范围。空白时段表示没有保留样本，升级不能补回已删除或从未采集的数据。
- 历史监控源查询支持最长三十天。源采集历史总容量默认由二十五万条提高到二百万条；十四个源每十秒采样时，七天约需八十四万七千条。仍受页面设置的保留天数与总容量共同约束，可通过 `DIRECT_MONITOR_MAX_SAMPLES` 设置二十五万至一千万条。请为持久化卷预留空间。

## 升级

将离线包中的 `upgrade_gateway.sh`、`all-images-arm64.tar` 和 `SHA256SUMS` 放入原部署目录，然后执行 `sh upgrade_gateway.sh`。脚本会导入镜像、备份环境文件并仅更新网关镜像标签。不要重新运行初始化、覆盖 `.env`、修改固定加密盐值，或删除数据卷。

只更新镜像时使用本版内置默认值；如要调整上述环境参数，请在原编排的网关 `environment` 段添加对应变量映射。原模型登记和采集关联会保留。

生产验收应使用实际已接入模型生成近一小时报告，检查报告状态、失败提示、修改生成和七天历史范围。没有覆盖所选范围的数据会如实显示缺失，不生成虚构历史。
