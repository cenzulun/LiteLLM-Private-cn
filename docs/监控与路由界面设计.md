# 监控与路由工作台

面向内网管理员在桌面浏览器中持续观察和调整模型服务。沿用现有导航、中文文案及登录品牌，采用蓝色操作主色、浅蓝灰工作区和白色数据面板；绿色只表示新鲜、可判断且未触发已配置阈值的数据，缺失或过期数据保留中性色。

推理监控以实例筛选、核心负载、可多选的趋势、指标明细为顺序；资源页只呈现引擎缓存、进程及设备指标；路由页以“运行态势”和“策略编排”两个标签分别展示真实实例流量、调用记录，以及配置与画布。首页保留网关令牌统计，将旧模型用量表替换为趋势及采集实例表。

采集源使用单项编辑，已有源作为选择列表。新增后只展开新源；测试、移除、新增、保存位于同一操作行。扩展设置默认收起，密钥只在当前表单内存在。

画布的连接编译为网关实际支持的全局均衡策略与模型组备用映射，不能将任意图形连接冒充可执行语义路由。节点可移动、添加和删除，连接顺序表示备用优先级；校验、发布、冲突保护及回退复用在线配置能力。发布不重启网关。

验收包含有数据、无数据、过期、错误、只读、桌面及窄屏状态。不同单位指标分别绘图，避免混合坐标造成误读；空值不补零。画布运行状态来自实际部署与路由事件，不生成虚假动画流量。
