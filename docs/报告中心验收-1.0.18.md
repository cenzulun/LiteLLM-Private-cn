# 报告中心验收 1.0.18

本地 AMD64 与 ARM64 仿真容器均完成完整服务启动，使用两个带鉴权的本地模拟模型接口进行验收，没有使用生产地址或生产指标。

只在模型与部署登记服务地址和密钥，未添加采集源，后台自动关联指标地址，鉴权采集成功。前端接口不返回密钥。模拟模型移除后，其自动关联源消失，原模型与采集配置保留。

报告按所选时间汇总已保留的指标、网关用量与路由事件，调用登记模型，生成固定模板。标准版包含整体情况、详细情况、分析与建议及离线图表。无效模型分析返回失败状态。报告对话生成独立修订版，原版和数据范围保留，对话记录可查询。

后台报告测试十一项、模型自动关联测试五项、原监控后台测试十五项通过。一项私有原始样本回放测试因容器未提供原始文件跳过。报告前端交互三项、原监控交互七项通过。生产构建、类型检查和代码规范检查通过，仍存在十二项复杂度与表达式风格警告。

浏览器验证覆盖宽度一千四百四十、七百六十八及三百九十像素。主标题唯一，报告列表在内部滚动，详情完整展示，下载文件包含图表，对话摘要更新正常，没有页面脚本错误或页面宽度溢出。相关记录随部署包交付。

AMD64 另经容器重启后复验，报告内容校验和及对话记录保持一致。ARM64 验证完整服务启动、功能链路和独立进程读取持久化报告，本版未再重复 ARM64 容器重启。未在目标 openEuler ARM64 主机、生产模型或昇腾设备上验收。真实分析质量还取决于所选模型、历史覆盖和实际暴露的指标。
