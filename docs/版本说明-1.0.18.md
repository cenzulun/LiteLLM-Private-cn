# 版本说明 1.0.18

运行监控新增报告中心，可选择统计时间、报告名称及已登记的对话模型。后台汇总该时段保存的源采集指标、网关令牌与调用、路由事件及已配置的历史监控数据，调用所选模型进行结构化分析，再生成固定模板的独立 HTML。列表展示报告名称、统计时间、生成时间、生成用户和状态，详情在右侧展开，支持下载。

标准版包括整体情况、详细情况、分析与建议，附模型请求、实例排队、设备利用率对比和趋势图。详情增加报告对话，可按要求生成修订版，保留原报告、对话与冻结数据。生成前也可填写自定义要求。

报告任务及结果保存在原持久化状态卷，离开页面不影响生成。只读管理员可查看，管理员可生成。生成失败会显示失败状态，不以空白报告冒充成功。最多选择三十天，实际可用历史以采集保留周期为准，无法补回启用采集之前的数据。

模型与部署中登记的模型默认自动关联指标采集。从基础地址推导同主机的 `/metrics`，后台复用模型密钥，前端不返回密钥原文。新增、副本变更、模型密钥变更及删除均自动同步。已有手工绑定优先。独立指标端口或特殊路径可在源采集配置中修改，指标地址位于其他主机时需配置独立凭据。自动发现可关闭。

模型服务本身必须开放指标接口。只有模型调用接口时，平台无法推断未暴露的排队、缓存或设备指标。昇腾卡监控仍需实际设备指标导出器，历史监控入口继续保留。

报告使用的模型只接收汇总指标，不接收服务地址、密钥、提示词和回复正文。网关令牌与引擎令牌保持各自口径，累计计数按观测增量处理重置，缺失数据不补零。分析输出作为数据转义后进入固定模板，详情使用隔离框架展示。

已有部署可以保留原数据库、缓存、环境配置和状态卷升级，无需重新初始化。升级前备份数据库、环境文件及状态卷，使用随包升级脚本更新网关镜像。固定加密盐值必须保留，不能使用新环境文件覆盖原文件。
