## 自动检查与交付检查

完成前端生产构建、相关组件测试、密钥加密与撤销测试、告警去重及恢复测试、采集器测试与定向静态检查。包内 `verification` 目录保留可复核的结果，`release-validation-1.0.21.json` 记录两种架构实际运行的镜像标识、健康状态及页面与后台源码一致性。

完整交付包包含网关及路由引擎 ARM64 镜像、外部 PostgreSQL / Redis 编排、初始化及升级脚本、源码和校验清单。离线包验证另外检查镜像架构、全部文件摘要、外部数据库与缓存配置、重复初始化拒绝覆盖原环境，以及未夹带环境密钥与现场指标样本。

## 验收边界

ARM64 验证环境为本地仿真容器，不能替代目标 openEuler 主机及生产推理引擎的现场验收。历史密钥若仅保存摘要，无法还原原文；新建密钥支持加密保存及管理员查看。告警历史从升级后采集开始积累。

升级只替换网关镜像，沿用原环境文件、数据库和持久化卷；单实例容器更新期间会有短暂访问中断，不重新初始化系统。
