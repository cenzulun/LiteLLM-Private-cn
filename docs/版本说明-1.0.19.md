# 版本说明 1.0.19

修复通过 HTTP 内网 IP 或普通内网域名访问时，点击生成报告和发送报告修订提示提交失败的问题。原页面在提交前调用仅安全上下文支持的浏览器随机编号接口，导致请求未发出，错误提示却指向权限或模型配置。

现在请求编号由后台生成，使用已有接口的默认编号机制，报告生成和对话修订均支持普通内网 HTTP 访问。真实接口返回的权限、参数和服务错误仍按原流程显示，未收到接口错误时不再笼统归因为权限或模型配置。

报告生成要求默认展开。新增定时报告任务，每小时、每天或每周按北京时间执行，可设置分析模型、最近一至七百二十小时的统计范围及独立生成要求，并支持编辑、启停、删除、立即执行及查看最近报告。

定时任务与报告共用已有状态卷，后台自动建表。多工作进程通过数据库事务确保每个任务每轮只入队一次；离线期间错过的周期合并补执行一次，统计截止恢复后实际入队时刻；队列达到上限时延后。删除任务不删除已有报告。

本版只更新网关镜像，调度服务镜像保持原版。沿用原环境文件、数据库、缓存及持久化卷，不需要初始化。升级完成后刷新浏览器页面以加载新静态文件。固定加密盐值必须保留。
