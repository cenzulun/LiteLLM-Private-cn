# 后台操作页面

页面唯一主标题位于顶部导航栏，字号十六像素，字重六百；正文不重复页面名称和页面介绍。内部区块标题使用十六像素，子区块使用十四像素。登录页面属于独立展示界面，不套用后台的紧凑标题规则。

内容从操作栏、筛选和数据开始，统一十六像素页边距，主要区块之间十六像素间隔。创建、配置、刷新操作保留在现有入口；发布、校验、回退位于编辑器上方。窄屏允许操作栏换行，表格在容器内横向滚动，整页不得横向溢出。

重复描述直接删除；统计口径默认收起，错误和告警继续可见。涉及字段含义、权限和操作结果的必要提示放在相应控件附近，不将页面写成部署说明书。

验收从完整导航入口清单开始，登录后等内容加载完成再统计标题、测量控件位置和截图。检测重复主标题、字号不一致、初始操作远离顶部、横向溢出及脚本错误。检查桌面、窄屏、无数据与有数据状态，以及配置、筛选、保存等操作；不能只用代码扫描或局部截图代替全站页面验收。
