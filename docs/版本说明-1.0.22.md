# 1.0.22 更新说明

本版修正已部署模型列表的操作位置。移除列表最前方重复的操作列，把修改按钮合并到原有右侧操作列，与启停、删除集中展示。操作列固定在右侧，横向查看其他列时仍可使用。

模型修改沿用原接口、权限和保存逻辑，保存后刷新列表。本版仅调整前端，不变更数据库或后台路由能力。

升级只需更新网关镜像。把离线包内的 `all-images-arm64.tar`、`SHA256SUMS` 和 `upgrade_gateway.sh` 放到原部署目录，执行 `sh upgrade_gateway.sh`。保留原 `.env`、数据库及持久化卷，无需重新初始化。单实例更新期间会有短暂访问中断。

1.0.21 的十三项改动继续保留，详见《版本说明-1.0.21》。
