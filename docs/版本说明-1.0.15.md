# 1.0.15 资源页操作栏修正

“引擎与昇腾资源”页面的右上角统一排列“配置源采集”“配置监控源”“刷新”，两个配置入口位于刷新之前。配置默认收起，点击对应按钮展开，不再在页面上方常驻两块配置区域。

本版只调整资源页操作栏。源采集指标、资源状态、资源表格、趋势和告警的显示规则沿用 1.0.14；没有再次扩大隐藏范围。新增针对资源页完整组件的回归测试，核验按钮顺序、默认收起、配置展开以及指标区保留。

升级只更新网关镜像到 `realai/gateway:1.0.15-arm64`，沿用原 `.env`、加密盐值、Compose 项目名、数据库与持久化卷，不重新初始化。单网关容器更新存在短暂中断。
