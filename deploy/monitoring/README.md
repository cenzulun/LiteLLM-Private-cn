# 内网监控接入

本目录提供 Prometheus 的内网采集样例和告警规则。生产环境应根据 Kubernetes 服务标签、端口和实际指标名称调整配置。

智能路由页面新增网关专属指标 `realai_route_*` 和 `realai_gateway_*`，由同一 `/metrics` 采集，不增加采集服务。必须分别采集各网关容器，不能只采集网关负载均衡地址。进程内计数由已有双进程采集机制合并，重启前的历史保存在监控源。至少等待两次采集后才能计算增量和速率，升级前的数据不会补录。

路由调用数按上游尝试统计，包括重试和备用调用。客户端请求按逻辑请求统计。分位时延不能直接相加或平均。首令牌时延仅对观测到输出内容的流式请求产生；令牌用量仅记录上游返回的用量。备用成功率按已完成的备用尝试计算，不等同于整个备用链最终救回率。取消单独计数，成功率的分母包含已完成的取消尝试。

页面的“配置监控源”持久化保存查询地址与指标映射。路由查询模板允许 `@scope@` 和 `@window@` 占位符，分别替换模型与实例筛选标签以及所选累计窗口。自定义映射须保留对应维度。引擎指标优先关联 `metadata.instance` 或 `metadata.route_instance` 与采集标签；同机多端口仅主机标签无法唯一匹配时不显示实例压力，也不会据此选择实例。运行和排队计数按匹配序列求和，排队分位时延多序列取最大值，不能理解为合并后的总体分位。

近期调用记录位于已有 `motor_module_state` 卷中的 `routing.sqlite3`，保留三十天且最多两万条，页面每次最多读取一百条。只保存模型、实例、选择依据、结果、耗时和归类失败原因，不保存提示词、回复正文、原始错误内容或密钥。单机双进程共用此文件，多主机各自保存本机记录；跨主机历史统计以监控源为准。

告警规则已包含路由失败率、备用调用失败和调用时延，需合并加载 `realai-alerts.yml`。阈值是初始样例，应按模型输出长度及现场负载调整。页面通过监控源的 `/api/v1/alerts` 展示活动告警，空列表并不能证明已加载规则。站外通知由现有告警系统负责。

将样例的采集任务合并到已有配置，不能直接覆盖现有配置。网关目标地址使用内网宿主机的映射端口（默认 4100），容器网络内可使用 `gateway:4000`。网关指标接口需要鉴权，将专用监控调用密钥写入监控服务的 `/etc/prometheus/secrets/gateway-token`，只包含密钥本身；账号需要具有读取指标的权限。不要将密钥写入可公开的配置库。

集群自动发现需要现有监控账号具有跨目标命名空间读取与监听 `pods` 的权限。推理容器必须把实际指标端口声明为 `name: metrics`；导出器模板已声明该名称。样例保留 `instance=主机:端口`，避免同机多模型端口被混为一台实例。如模型地址使用服务域名，而监控使用容器地址，请在每个模型部署参数的 `metadata.instance` 或 `metadata.route_instance` 指定与监控一致的实例标识。自动感知路由需要每个独立上游副本都有单独模型部署配置，只有一个负载均衡服务地址时不能选择其内部容器。

## 节点侧

在每台昇腾推理节点部署华为 MindCluster 中的 NPU Exporter，推荐使用 DaemonSet。Prometheus 采集 NPU Exporter 的 `/metrics`，并保留 `instance`、`node`、设备编号等标签。

`npu-exporter-daemonset.yaml` 是部署模板。镜像地址、版本、端口和昇腾驱动挂载目录必须按内网实际安装位置修改，模板中的占位镜像不会直接拉取公网镜像。

## 推理服务侧

在 vLLM-Ascend 服务中安装并启用 `ms_service_metric`。每个服务实例使用独立的 `PROMETHEUS_MULTIPROC_DIR`，避免多实例互相覆盖指标文件。启用后确认服务的 `/metrics` 中出现 `vllm_profiling_` 前缀指标，再加入 Prometheus 采集。

## 网关侧

在网关 `.env` 中配置：

```dotenv
PROMETHEUS_URL=http://prometheus.intra:9090
REALAI_METRIC_ROUTING_ENABLED=false
REALAI_ROUTING_METRIC_REFRESH_SECONDS=10
```

先保持指标感知路由关闭，确认监控数据和标签匹配后再设置为 `true`。启用后网关按运行请求数与等待请求数选择实例，查询失败或标签不匹配时自动回退到历史时延路由。

## 版本差异

vLLM、vLLM-Ascend 和 NPU Exporter 的指标名称可能随版本变化。请在 `curl http://实例地址/metrics` 和 Prometheus 查询页确认实际名称，再使用 `deploy/monitor-queries.json` 覆盖网关查询表达式。
